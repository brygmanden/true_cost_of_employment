# True cost of employment

A self-contained, 3-slide HTML carousel comparing employer on-costs in Australia, the United Kingdom and the USA.

- `index.html` – open it directly, or copy everything between the `START` and `END` comments into any page body.
- Max width 750px, with a phone layout below 560px.
- Fonts (Head-Bold, NoBH-Bold, NoBH-Regular) load from baristahustle.com.
